HOW TO CHANGE THE VIDEO
========================

1. Get your new video file (must be .mp4 format).
2. Rename it to exactly:  video.mp4
3. Drag it into this folder, replacing the old one (say "yes" to overwrite).
4. Done. index.html always plays whatever is named video.mp4 - no code changes needed.

If the site is only on your computer:
- Just double-click index.html to preview in your browser after replacing the file.

If the site is already live (deployed to a host):
- You'll need to re-upload video.mp4 to wherever it's hosted (same steps depend
  on the host - e.g. push to GitHub, drag into Netlify, upload via FTP, etc).
- Ask me once you've picked a host and I'll set up a one-step way to push updates.

Converting a video to .mp4 (if yours is a different format like .mov):
- Use any free converter, e.g. https://cloudconvert.com/mp4-converter
- Or ask me and I'll convert it for you if you give me the file.
